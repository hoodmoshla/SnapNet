QuickJS-ng (libqjs.so)
======================
Files: arm64-v8a/libqjs.so, armeabi-v7a/libqjs.so, x86/libqjs.so, x86_64/libqjs.so
Upstream: https://github.com/quickjs-ng/quickjs
Version: 0.17.0
License: MIT

QuickJS-ng is a JavaScript engine used as yt-dlp's external-JS (EJS) challenge solver. yt-dlp
requires a JS runtime for full YouTube support; SnapNet passes the path of this binary to yt-dlp via
`--js-runtimes quickjs:<path>`.

These binaries are statically linked against musl so that they can execute without bionic's dynamic
linker. They are built from unmodified upstream sources by tools/build-quickjs.sh.
