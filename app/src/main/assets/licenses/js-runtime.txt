QuickJS - the JavaScript runtime used by yt-dlp
==============================================
Ships as: lib/<abi>/libqjs.so, one copy per ABI, supplied by the youtubedl-android library
          (io.github.junkfood02.youtubedl-android:library), version 0.18.1.
Upstream: https://bellard.org/quickjs/
Version:  2025-04-26
License:  MIT

yt-dlp needs a JavaScript engine to solve YouTube's signature and `n` challenges and to work with
its external-JS (EJS) components. youtubedl-android bundles QuickJS for every supported ABI, ships
the yt-dlp-ejs package alongside it, and appends `--js-runtimes quickjs:<path>` to each yt-dlp
invocation it runs.

SnapNet does not build or bundle its own copy: an earlier revision shipped a locally compiled
QuickJS-NG in jniLibs, which duplicated the library's engine and was removed once the library began
providing one.
